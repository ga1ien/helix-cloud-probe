What is in the box

Small surface area, deliberate details.

  • ⚡

    Zero dependencies

    node:http, node:fs, node:path — nothing to install, nothing to audit, nothing to rot.

  • 📱

    Responsive by default

    Fluid type with clamp(), grid auto-fit cards and a single mobile-first stylesheet that holds up from 320 px to ultrawide.

  • 🔒

    Safe by construction

    Static files are path-contained, so ../ traversal attempts get a clean 404 instead of your server source.

  • ♿

    Accessible

    Semantic landmarks, a skip link, visible focus rings, live status text and prefers-reduced-motion support.

  • 🌗

    Theming

    Dark and light palettes follow the OS, and the in-page toggle remembers your choice in localStorage.

  • ✅

    Checked

    npm test boots the server on an ephemeral port and asserts routes, headers, content types and traversal safety.

The whole stack

Run it

npm start
# Hello Kulti running at http://localhost:3000

Zero install step. Any Node.js ≥ 18 works; PORT and HOST are configurable env vars.

Layout

server.js          zero-dep HTTP server
public/index.html  markup
public/styles.css  responsive styles
public/app.js      progressive enhancement

Everything the browser needs ships from one folder.
